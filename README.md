### Моделирование течения Пуазейля методом LBM

Течение Пуазейля - тестовый пример для LBM, простая задача с аналитическим решением (параболический профиль скорости).
Позволяет опробовать несколько концепций LBM: основной цикл симуляции, граничные условия, силы.
В данном случае используются no-slip граничные условия (нулевая скорость на стенках) и периодические слева/справа.
Сила прикладывается одинаковая ко всем ячейкам сетки.
Код симуляции лежит в solver.cpp, после компиляции его с оптимизацией -O3 получились ожидаемые результаты.
Значение ux в максимуме согласно аналитическому решению составляет

$$
\frac{F_x N_y^2}{\frac{8}{3}(\tau-0.5)}
$$

В ноутбуке analysis.ipynb проведен анализ, как изменятся результаты и время выполнения при изменении параметров.
Все формулы для моделирования взяты из книги the_lattice_boltzmann_method_principles_and_practice_1st_ed.


### Моделирование конденсатора

Самый простой способ смоделировать конденсатор. Используется функция h (распределение потенциала) и граничные условия

$$
h_{right} = 0; h_{left} = 1
$$

Которые моделируются как (на правой стенке):

$$
h_{налево} = -h_{направо} + 2h^{граничное}_{налево}
$$

LBM решает уравнение диффузии (с производной по времени), а надо решать Пуассона. Поэтому фактически используется метод установления: решается диффузия до того момента пока потенциал не перестанет менятся (d/dt = 0).
Для установления нужного линейного профиля потребовалось 10000 шагов. Однако, в статьях Jiang Qu и Shan Liu по видимому делают именно так. Они говорят, что если немного изменить концентрацию, то и потенциал меняется несильно и для такой небольшой корректировки достаточно одного шага. Можно попробовать воспользоваться идеей Chai Shi для решения Пуассона.
